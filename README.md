# Real-Time Face and Feature Detection

## Project Description

This project uses Python and OpenCV to detect human faces and eyes in real time through a computer webcam. It captures live video frames, converts them to grayscale, and uses pre-trained Haar Cascade classifiers to detect faces and eyes.

## Tech Stack

- Python
- OpenCV
- Haar Cascade Classifiers

## Features

- Real-time webcam processing
- Human face detection
- Eye detection
- Grayscale image processing
- Real-time bounding boxes

## How to Run

Install OpenCV:

pip install opencv-python

Run the project:

python face_detection.py

Press Q to close the webcam window.
